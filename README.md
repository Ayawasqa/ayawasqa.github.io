# Ayawasqa 10 años · Catálogo

Sitio de una sola página (Astro 7.3.8, estático) de la Colección La Paz. Se apaga después del evento.

    npm ci
    BASE_PATH=/ayawasqa-10/ SITE_URL=https://ayawasqa.github.io npm run build

`src/data/productos.json`, `src/assets/productos/` y `src/components/Logo.svg` son salida de un generador externo.
